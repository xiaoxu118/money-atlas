## 机制分析

政策利率首先影响相关短期资金价格，再通过银行定价、债券市场和预期传到融资成本。不同合同重定价时间不同，企业与家庭也不会同时作出相同反应。

## 关键口径与风险分解

| 环节     | 加息时的可能影响   | 条件                 |
| -------- | ------------------ | -------------------- |
| 新增贷款 | 融资更贵           | 银行传导、风险定价   |
| 存量贷款 | 部分利息支出上升   | 是否浮动、何时重定价 |
| 支出决策 | 部分扩张或消费延后 | 收入预期与借款约束   |

## 情景核对

同一日，一笔固定利率旧贷款可能不变，新贷款报价却已提高。两者不矛盾，因为合同与定价时点不同。

## 进一步分析

政策传导应区分政策立场、市场预期和意外信息。长期利率可能在政策宣布前变化，银行也会根据借款人信用重新定价，因此应观察各期限市场利率与信用利差，而非只对比政策利率的单次变动。

## 理解的边界

这里只说明可能方向，不给出通胀或资产价格的精确反应。降息也不保证借款需求必然上升。
