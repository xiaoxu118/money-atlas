## 实物流、收入流与融资流需要分别记账

生产形成增加值，并通过劳动报酬、经营收益等形式形成收入。商品和服务的交付对应支出，但融资与既有金融资产买卖可能只改变资产负债结构，并不对应当期新增生产。

| 流量           | 核心对象               | 容易混淆的项目                 |
| -------------- | ---------------------- | ------------------------------ |
| 实际生产       | 当期商品与服务的增加值 | 重复计入中间投入               |
| 收入分配       | 劳动报酬、经营收入等   | 把所有银行入账都当新增收入     |
| 支出与资本形成 | 最终消费、投资等       | 把购买既有股票当作新增生产投资 |
| 融资交易       | 借贷与金融资产交换     | 把融资到账与企业利润等同       |

## 储蓄与投资的部门衔接

家庭未消费的收入不等于经济活动永久消失；它可能对应金融资产积累，并通过其他部门的融资与支出形成联系。在国民核算中，储蓄投资差额与对外账户有会计关联，但会计恒等式本身不证明某个部门行为必然导致另一个变量变化。

## 生产能力与需求约束

信用扩张放松融资约束后，是否增加实际产出取决于设备、劳动、原料、技术和需求。产能接近约束时，新增支出可能更多反映在价格上；需求疲弱或信用风险较高时，新增流动性也可能没有转化为新增贷款与投资。

## 利润不等于现金流

企业在确认收入与成本时采用会计规则，应收账款、库存、折旧和资本开支会使利润与经营现金流不同。分析企业融资能力，应把利润表、现金流量表及资产负债表连起来看，而非仅观察账户余额上升。

## 分析边界

闭合的家庭—企业循环只是一个截面。政府、金融部门与境外交易会改变资金流及风险分布，不能把全部工资立即消费或把资产涨价等同于产出增长。
