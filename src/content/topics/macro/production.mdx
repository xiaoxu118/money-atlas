## 问题从这里开始

贷款批下来了，面包会自动变多吗？

## 四条需要分开的流

| 类型           | 方向          | 内容     |
| -------------- | ------------- | -------- |
| 劳动流（实际） | 员工 → 面包店 | 提供劳动 |
| 工资流（支付） | 面包店 → 员工 | 支付工资 |
| 商品流（实际） | 面包店 → 居民 | 交付面包 |
| 消费流（支付） | 居民 → 面包店 | 支付货款 |

居民的支出可以成为企业的收入，工资又为消费提供支付能力。但工资不会必然全部用于消费，储蓄、税收、政府支出和对外交易都会影响循环。

## 融资与生产的边界

贷款扩大融资能力，实际生产增加商品。能否生产更多，还取决于设备、原料、劳动和技术。资金到位，原料却断供，产出未必增加。

金融资产价格上升也不等于实际产出增加。判断一个故事，需要问：账户变了，还是商品变多了？

## 一个具体例子

居民向面包店付 100 元，同时收到面包。资金和商品沿相反方向流动；不能把支付金额直接当成新增存款。
