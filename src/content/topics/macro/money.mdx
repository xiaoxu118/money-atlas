## 问题从这里开始

面包店借到 10,000 元，账户余额增加了。它是否因此多了 10,000 元净财富？

## 货币让交换更容易

没有货币，面包师想换鞋，必须找到既有鞋又想要面包的人。货币把卖出面包和购买鞋子拆成两次交易。

货币有三项职能：**交换媒介**、**计价单位**、**价值储藏**。价值储藏不代表购买力永远不变，通胀会影响未来能买到多少商品。

| 概念     | 含义                                                       |
| -------- | ---------------------------------------------------------- |
| 现金     | 公众持有的纸币和硬币，可用于支付；发行安排因国家而异。     |
| 银行存款 | 持有人的资产，也是银行的负债，本文以可支付的活期存款为例。 |
| 资产     | 现金、存款、房屋、设备等具有经济价值的资源。               |
| 负债     | 未来需要偿还的义务，例如贷款本金。                         |

**净财富 = 资产 − 负债。** 借入 10,000 元，存款资产增加 10,000 元，贷款债务也增加 10,000 元，借款瞬间净财富变化为零。

## 结果解释与边界

放贷可以创造存款；用存款偿还本金，对应的贷款和存款一起减少。转账只改变持有人。银行受资本、流动性、监管、信用风险和借款需求约束，不能无限放贷。

央行提供现金与银行准备金；准备金主要用于银行间结算。不要把准备金当成银行按固定倍数无限放大的原料。利息的会计处理不在本实验中。
