# 钱图（Money Atlas）：知识图解与交互探索架构

更新：2026-11-16。本文以当前产品定位为准：围绕问题、概念和实验组织内容，用户可以自由查阅各主题。

## 产品结构

网站提供三个入口：知识图解、概念索引、交互实验。首页按问题展示主题卡片；每篇主题独立解释问题，结合例子、公式、实验、模型边界和资料来源。主题之间通过相关概念建立联系，无固定阅读顺序或阅读门槛。

不设置课程、学习路线、章节完成状态、预计学习时长、前置要求、测验或课程收藏。此前相关界面、存储与内容字段已经删除；旧浏览器数据不读取、不覆盖。

## 技术边界

| 层次 | 实现 | 职责 |
| --- | --- | --- |
| 页面与构建 | Astro 静态输出 | 路由、导航、正文和元信息 |
| 内容 | MDX + Content Collections | 主题摘要、正文、概念引用、资料来源和发布状态 |
| 交互 | React + TypeScript | 实验输入、步骤、即时结果 |
| 样式 | Tailwind CSS + CSS 变量 | 响应式布局、主题与焦点样式 |
| 基础控件 | 本地组件 + Radix | Slider、Button，按 shadcn/ui 的源码维护方式组织 |
| 图解 | SVG | 公式结果对照与手动分步记账 |
| 模型 | 纯 TypeScript | 输入校验、金融公式与记账状态 |
| 验证 | Astro 检查、Vitest、Playwright | 类型、内容引用、金融模型、关键浏览与实验流程 |

Node 基线为 22.17.0，`.nvmrc` 与 CI 同步。锁文件固定依赖；Astro 的 `unifont` 使用其允许范围内的 0.7.4，保持 Node 兼容。

首版不依赖后端、数据库、账户或实时行情。交互实验按需加载，首页、主题与概念说明都能在关闭 JavaScript 时阅读。一个实验的输入、计算与解释属于同一 React 根组件。

## 目录与依赖

```text
src/
  pages/knowledge/        # 知识图解、宏观目录、主题路由
  pages/concepts/         # 概念摘要与关联主题
  pages/labs/             # 实验索引
  pages/learn/            # 历史地址兼容跳转
  layouts/                # SiteLayout、TopicLayout
  content/topics/macro/   # 独立 MDX 主题
  data/                   # 概念、实验注册、链接工具
  components/navigation/ # 主题卡片
  components/teaching/    # 模型说明与实验步骤控制
  components/ui/          # 独立基础控件
  experiments/            # 记账、利率、购买力
  models/                 # 无 React/DOM/存储依赖的纯计算
  lib/                    # 内容查询与引用校验
  styles/                 # 全局设计变量与样式
public/                   # 旧 HTML 兼容入口、原型归档
scripts/                  # 构建后内部链接与锚点检查
tests/                    # 模型、内容校验与浏览流程
```

页面和 MDX 组合布局、正文与实验；实验依赖模型和基础组件；模型不依赖界面、动画或浏览器。概念与实验索引链接同一份主题内容，不复制正文。

## 主题内容约定

元数据包含稳定 ID、slug、title、module、summary、displayOrder、concepts、updatedAt、status 和 sources。displayOrder 只表示卡片展示位置。没有前置关系、预计时长或完成状态字段。

构建检查 ID 唯一、路径唯一、概念存在、概念与实验引用已发布主题；草稿不生成主题页面或进入目录。构建后检查内部链接和锚点。MDX 仅由可信仓库作者维护。

正文按实际问题组织，可以包含概念说明、例子、结果解释、图解、实验和模型边界。避免强制套用章节学习模板。

## 模型与交互约定

- 一年单利明确本金、示例贷款年利率、计息期限、费用范围与舍入方式；政策利率不能直接等同个人贷款利率。
- 购买力模型明确固定通胀假设、期限和预算不变，不表示未来预测。
- 记账实验核对银行与客户资产负债，内部转账不改变存款合计，还本对应减少。
- 政策与供需情景说明可能方向、条件和时滞，不输出虚构的精确预测。
- 输入变化即时计算，动画只表现结果，不依赖动画完成回调计算金融状态。
- 分步实验仅手动切换上一步、下一步或重置，不提供自动推进、播放控制或播放计时器。
- 滑块可用键盘操作，标明单位；图解有文字、数值或表格对应，默认结果可静态阅读。
- 动态效果遵循 `prefers-reduced-motion`，响应式布局避免手机横向溢出。

## 路由、兼容与部署

主要路径为 `/`、`/knowledge/`、`/knowledge/macro/`、`/knowledge/macro/[slug]/`、`/concepts/`、`/concepts/[id]/`、`/labs/`。

旧 HTML 地址和七个章节片段映射到对应主题，历史 `/learn/` 路径保留片段感知跳转。兼容地址不加入站点地图。原始源码保存在 `public/archive/prototype/`，不作为正式导航入口。

静态部署目录为 `dist/`。确定生产域名后设置 `SITE_URL` 生成 canonical 与站点地图；主机专属永久重定向随后配置。CI 使用锁文件安装，执行类型、模型和内容验证、构建、内部链接检查及浏览器流程测试。

后续可增加投资知识主题与独立实验，但应维持自由查阅的产品结构，并单独验证新增模型。
