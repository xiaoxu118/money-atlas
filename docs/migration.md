# 知识网站重构实施记录

更新：2026-11-16。产品定位调整为知识查阅与交互探索。

## 当前调整

- 首页展示问题与主题卡片，主导航为“知识图解 / 概念索引 / 交互实验”。
- 七篇宏观知识说明独立浏览；无编号顺序、阅读时长或前置门槛。
- 移除课程路线、学习目标、下一课、完成记录、课程收藏和小测；相关组件、进度存储模块与元数据字段同时删除。

- 正式地址改为 `/knowledge/`；此前 `/learn/` 地址仅作兼容跳转，保留 URL 片段。原 HTML 入口和七个章节锚点同步指向新地址。
- 不再读取或写入 `touziLab` 或 `touzi-lab:progress:v1`，已有浏览器数据保留原样。动态效果遵循系统偏好。

## 验证与环境

Node 基线为 22.17.0，CI 读取 `.nvmrc`；固定兼容的 `unifont@0.7.4`，严格 engines 检查安装通过。

验证覆盖类型检查、模型与主题引用、静态构建、内部链接与锚点、关闭 JavaScript 阅读、键盘输入、实验手动切换与重置、移动端和减少动态效果、概念筛选、旧地址兼容，以及主要页面中不再出现课程或进度界面。

本机浏览器验证使用已安装的 Chrome，命令为 `PLAYWRIGHT_CHANNEL=chrome npm run test:e2e`；CI 使用 Playwright Chromium。桌面 1440px、手机 375px 截图位于 `docs/screenshots/`。
