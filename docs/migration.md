# 钱图内容改造记录

## 已完成范围

根据 outline 补齐全部 64 篇主题，保留稳定 ID 和可用旧入口。金融原理 30 篇分 9 组，投资 34 篇分 6 组，共 151 个概念。

- 内容从启蒙式问答改为机制分析：重写货币、结算和生产原文，删除低密度的生活问题、以物易物铺垫及简单词义表；全部标题直接指出分析对象。
- 新内容覆盖期限错配、利率口径、GDP、国际收支、组合风险、各类资产、基金穿透、费用、杠杆、估值、托管、税务与行为。
- 每篇先展示实际 SVG 图解，再展开说明。定量图涵盖复利、费用、债券、期限结构、回撤、杠杆、期货与期权；其他主题以各自的机制图表达关系，附具体对照和边界。
- 首页提供两大板块入口，知识导航使用 15 个紧凑分组，正文页面不再复制导航页的列表。
- 恢复分层侧栏：板块、分组、主题三级，默认展开当前位置，原生折叠支持键盘，手机收拢目录。
- module 参与链接生成和动态路由，金融原理与投资互相衔接；黄金、风险、利率与基金穿透等主题有明确的对应阅读。

## 验证

- Astro / TypeScript 无错误和警告。
- 金融模型、大纲覆盖、双向概念关系、固定情景计算和图轴数据校验。
- 浏览器遍历全部 64 篇主题的桌面与手机布局：页面可直接访问、有 SVG、图在解释之前、无横向溢出。
- 验证三级侧栏展开、高亮、跨板块跳转、手机目录、概念筛选与旧锚点兼容。
- 构建后检查所有内部链接与锚点，站点地图排除历史地址。

本机使用 Node 22.17.0 和已安装的 Chrome，CI 使用 `.nvmrc` 与 Playwright Chromium。截图位于 `docs/screenshots/`。

## 保留的边界

没有恢复课程、测验、进度、实验、播放或重置功能，不显示更新时间。图表和正文无需 JavaScript 即可阅读。

数字与曲线是条件明确的简化模型，不给产品推荐、配置比例或价格预测。地区制度来源仅支持相应概念和范围，不直接充当其他地区的法规指南。尚未部署。
