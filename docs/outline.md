# 钱图内容大纲

更新：2026-11-16

内容规划清单。站点是自由查阅的知识库，本大纲只用于组织素材和安排写作，不代表站内阅读顺序，也不设前置要求。

现状：7 篇主题已发布、9 个概念、3 个实验。下表中 `已发布` 的有页面，`待写` 的已确定标题和概念引用，`可选` 的视精力再排。

## 使用约定

- 一篇主题回答一个问题，标题用问题或判断句，不用单个名词。
- 成对概念合并到同一篇：加息/降息、通胀/通缩、名义/实际、单利/复利、固定/浮动。
- 术语进概念索引，不单独开篇；概念先在 `src/data/concepts.ts` 注册。
- 层级只用于排写作顺序（核心、进阶、可选），不在站点上展示。
- 新实验先在 `src/models/` 写纯计算，再到 `src/data/experiment-registry.ts` 登记并挂到主题锚点。
- `module` 目前只有 `macro` 有路由；`investing` 已在 schema 预留，但页面和导航未建，暂不发布 `module: investing` 的内容。
- `displayOrder` 写作时统一分配，同模块相邻；已发布主题的现有顺序不变。

资产类别的深入内容——债券、股票、基金、贵金属渠道、房地产、期货、期权等——放在投资模块，见[投资内容大纲](outline-investing.md)。这里只保留概览和概念卡。

### 黄金与白银的边界

- 基础层写：物理属性与供给、需求结构、价格驱动（实际利率、美元、避险情绪、通胀预期）、金本位简史、白银的工业需求与更高波动。
- 投资层写：购买渠道、买卖成本、仓位与相关性、真伪与保管。
- 不把「抗通胀」写成稳定规律，说明效果依时期而异。

## 待建概念

| id                      | 中文           | 一句话定义                                                   |
| ----------------------- | -------------- | ------------------------------------------------------------ |
| `central-bank`          | 中央银行       | 发行基础货币、设定或引导政策利率、为银行提供清算与最后贷款。 |
| `deposit-insurance`     | 存款保险       | 对限额内存款提供保障，降低挤兑动机。                         |
| `maturity-mismatch`     | 期限错配       | 短期限负债对应长期限资产，流动性紧张时容易出问题。           |
| `money-supply`          | 货币供应量     | 按流动性划分的 M0、M1、M2 统计口径。                         |
| `compound-interest`     | 复利           | 利息计入本金后继续计息。                                     |
| `present-value`         | 现值           | 未来一笔现金流按给定利率折算成今天的价值。                   |
| `annualized-rate`       | 年化利率       | 把不同期限的收益率折算成一年口径，便于比较。                 |
| `policy-rate`           | 政策利率       | 央行直接设定或引导的短期利率，是传导的起点。                 |
| `amortization`          | 还款摊还       | 分期归还本金和利息，本金逐期减少。                           |
| `yield-curve`           | 收益率曲线     | 不同期限债券收益率连成的曲线。                               |
| `term-premium`          | 期限溢价       | 长期利率中高于短期利率预期的补偿部分。                       |
| `core-inflation`        | 核心通胀       | 剔除食品和能源等波动项后的通胀指标。                         |
| `ppi`                   | 生产者价格指数 | 工业品出厂环节的价格变化。                                   |
| `inflation-expectation` | 通胀预期       | 家庭、企业和市场对未来价格变化的判断。                       |
| `nominal-vs-real`       | 名义与实际     | 是否扣除价格变化后的口径区别。                               |
| `gdp`                   | 国内生产总值   | 一定时期内境内生产的最终产品与服务价值。                     |
| `real-gdp`              | 实际 GDP       | 按不变价计算、剔除价格变化的 GDP。                           |
| `unemployment`          | 失业率         | 失业人口占劳动力人口的比例。                                 |
| `business-cycle`        | 经济周期       | 经济活动扩张与收缩的交替。                                   |
| `reserve-ratio`         | 存款准备金率   | 银行按存款一定比例缴存央行的资金比率。                       |
| `open-market`           | 公开市场操作   | 央行买卖证券以调节银行体系流动性。                           |
| `qe`                    | 量化宽松       | 央行大规模购买资产以压低长期利率的政策工具。                 |
| `fiscal-policy`         | 财政政策       | 政府通过税收和支出影响经济。                                 |
| `deficit`               | 财政赤字       | 政府支出超过收入的差额。                                     |
| `government-debt`       | 政府债务       | 政府尚未偿还的借款余额。                                     |
| `exchange-rate`         | 汇率           | 一种货币兑换另一种货币的比率。                               |
| `current-account`       | 经常账户       | 货物、服务、收入和转移的跨境收支。                           |
| `capital-account`       | 资本账户       | 跨境资本流动的收支记录。                                     |
| `risk-premium`          | 风险溢价       | 承担额外风险所要求的额外回报。                               |
| `volatility`            | 波动率         | 收益围绕均值的波动程度。                                     |
| `diversification`       | 分散           | 通过持有相关性较低的资产降低单一风险。                       |
| `opportunity-cost`      | 机会成本       | 选择一种用途而放弃的最佳替代用途的价值。                     |
| `liquidity`             | 流动性         | 资产在不明显折价的情况下变现的难易。                         |
| `asset-class`           | 资产类别       | 按现金流和风险特征划分的资产分组。                           |
| `store-of-value`        | 储值资产       | 主要用于保存购买力、不产生现金流的资产。                     |
| `gold`                  | 黄金           | 稀缺、可储存的贵金属，常被用作储备与储值资产。               |
| `silver`                | 白银           | 兼具货币属性与工业需求的贵金属。                             |
| `bond`                  | 债券           | 发行人承诺按约定支付利息并归还本金的债务凭证。               |
| `equity`                | 股票           | 公司所有权的凭证，收益来自利润分配与价格变化。               |
| `fund`                  | 基金           | 汇集资金、按既定策略投资的一篮子资产。                       |
| `index-number`          | 指数           | 以基期为 100 表示相对变化的统计量。                          |
| `yoy`                   | 同比           | 与上年同期相比的变化。                                       |
| `base-period`           | 基期           | 计算指数时作为参照的时期。                                   |
| `chart-misread`         | 图表误读       | 坐标轴、口径或图形选择造成的错误结论。                       |
| `direct-tax`            | 直接税         | 税负难以转嫁、由纳税人直接承担的税。                         |
| `progressive-tax`       | 累进税         | 收入越高适用税率越高的税制。                                 |

## 写作顺序建议

顺序只用于排期，不映射站内顺序。

1. 第一批：复利与时间价值、央行与货币工具箱、黄金与白银、GDP 与增长。
2. 第二批：加息与降息、通胀的度量、汇率与升贬值、风险与收益入门。
3. 第三批：银行体系与风险、经济周期、财政与国债、资产类别图谱、读懂一张经济图表。

## 边界

- 不推荐产品、不承诺收益、不预测价格；情景类内容标明条件与时滞。
- 每篇至少一个可核对来源，数字为教学示例。
- 涉及购买渠道、仓位、税费和交易成本的内容，留给 `investing` 模块。
